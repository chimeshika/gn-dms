# Branding asset

`sri-lanka-emblem.svg` is the standalone national emblem vector by Tonyjeff, with subsequent Wikimedia Commons revisions. The vectorization is released into the public domain on its source page:

https://commons.wikimedia.org/wiki/File:Emblem_of_Sri_Lanka.svg

Original download: https://upload.wikimedia.org/wikipedia/commons/5/5f/Emblem_of_Sri_Lanka.svg

The artwork is stored locally, unchanged. The GN-POMS wordmark and subtitle are rendered as accessible HTML in `src/components/Brand.jsx`; no screenshot crops are used.
