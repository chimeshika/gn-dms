# Previous interface

This folder preserves the previous Blade pages, Filament resources, and their controllers for reference during the React migration. These files are not routed, registered as providers, or included in Composer's application autoload paths.

The active UI is in `frontend/src`. The active controllers are in `backend/app/Http/Controllers/Api`. PDF templates remain active in `backend/resources/views/pdf` because Laravel generates those documents.
